# 慢慢走

一本从出发计划逐渐长成旅行回忆的个人轻手账网站。

当前处于设计与素材准备阶段，尚未提供可运行的网站。

## 第一阶段

- 地图入口与旅行封面列表。
- 南京作为第一册，状态为「计划中」。
- 出发前计划与按天记录分别保留。
- 内容与主题分离，为以后更换样式留下空间。

## 版本管理

使用 Git 保存代码、设计说明和经整理的参考资料。文本文件统一使用 LF；Windows 批处理文件使用 CRLF。

环境变量、数据库和本地上传目录已列入忽略规则。个人原始照片和私密旅行记录可存放在 `private/` 或 `local-data/`，不纳入版本库。
