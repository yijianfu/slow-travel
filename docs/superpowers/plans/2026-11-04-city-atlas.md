# 城市旅行地图 Implementation Plan

**Goal:** 将已确认的城市地图、重复旅行、未去清单落实为可操作的网站。

**Architecture:** 在现有 version 1 JSON 上添加城市清单、旅行城市关联、封面和感受。地图交互和城市页面拆成独立前端文件，保留既有编辑器、服务和访问权限。

**Tech Stack:** 原生 JavaScript / CSS、Node SQLite、Sites Worker / D1 / R2。

## 执行顺序

- [x] 数据：先添加迁移、封面备份和分享隔离测试，运行观察失败；扩展 `server/model.mjs`，让本地和托管 GET 都输出规范化数据，再运行测试。
- [x] 页面：添加 `dist/assets/atlas.js` 负责地图拖动缩放；添加 `dist/assets/city-pages.js` 负责城市卡片和未去清单；连接 `dist/app.js` 路由、表单和打卡操作；添加独立 atlas 样式。
- [x] 验证：运行 `npm test`（23 项通过）、`npm run build`；使用隔离浏览器实际创建城市、两次旅行、地点和美食，验证加入计划后保留、打卡后移出、取消恢复、删除打卡、选择封面、分享和移动端。代码复核修复独立封面清理问题，并验证分享快照中的封面保留。
- [ ] 发布：按 Sites 官方工作流准备源代码和归档，部署现有私人站点，确认部署成功并同步 GitHub。

## 核心约束

不修改用户线上内容作为测试；不更改私人访问范围；保留 ETag 冲突检测。备份与清理照片必须包含独立封面，分享中封面必须改写为只读照片路径。旧数据只在内存读取时迁移，保存时才写入增量结构。
