# 慢慢走：城市旅行地图

本轮按用户已确认的方向实现：首页纸质地图，可拖动、缩放至城市；城市作为入口，同一城市可有多次旅行。

- 城市页分开展示计划中、旅途中和已完成旅行。封面由用户从手记照片中选择或单独上传，配一句自己的感受；没有照片时留白。
- 每个城市保存跨旅行的未去清单，分地点、美食。加入旅行不会移出清单，只有手动打卡才移出；取消打卡且没有其他打卡记录时恢复。
- 删除计划或旅行时，重新核对其中的打卡；没有其他到访记录的地点恢复到清单，有其他到访记录的地点继续保留已去状态。
- 完成旅行不会自动完成其中的计划。重访地点直接写入新旅行计划，无需进入未去清单。
- 保留现有旅行、手记、照片、参考资料、备份和分享。旧旅行按城市归档，旧地点收藏迁入城市清单，不推断曾经到访。
- 分享只含指定旅行的文字、封面和手记照片，不包含城市清单或旅行计划。
- 页面按地图、城市、单次旅行逐层展开，减少同时显示的内容。移动端保持相同层级。

实现沿用原生前端和现有 JSON 数据存储；增量字段兼容版本 1 备份，不改已部署 SQL 迁移。坐标沿用离线 GeoNames 数据和地图署名。首页仅将已有城市作为标记，未定位城市保留可打开的列表入口。
